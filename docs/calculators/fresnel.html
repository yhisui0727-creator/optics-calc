フレネル反射率（s偏光・p偏光）

界面での反射率を偏光ごとに計算し、入射角 0〜90° の変化を折れ線グラフにします。ブリュースター角では p偏光の反射率が 0 になります。角度の単位は「°」です。

s偏光 Rsp偏光 Rp点線：現在の入射角
使っている式
rs = (n₁cosθᵢ − n₂cosθₜ) / (n₁cosθᵢ + n₂cosθₜ) rp = (n₂cosθᵢ − n₁cosθₜ) / (n₂cosθᵢ + n₁cosθₜ) Rs = rs² , Rp = rp² , 無偏光 R = (Rs + Rp) / 2 ブリュースター角 θB = arctan(n₂ / n₁) 全反射域では Rs = Rp = 1 （θₜ はスネルの法則 n₁ sin θᵢ = n₂ sin θₜ で求める）
