ガウシアンビームの広がり

レーザー光は、断面の明るさが中心ほど強い「ガウシアンビーム」になっています。ビームは一番細いところ（ビームウェスト）から離れるほど太くなります。波長とウェストの半径から、距離 z でのビームの太さ（半径）や、太さが √2 倍になる距離（レイリー長）を求めます。空気中を進むとします。長さの単位は「mm」（633 nm = 0.000633 mm）、角度は「°」です。ビームの半径は、明るさが中心の 1/e²（約13.5%）になるところまでの長さです。

ビーム半径 ±w(z)±zR（レイリー長）点線：入力した z
使っている式
レイリー長 zR = π · w₀² / λ ビーム半径 w(z) = w₀ · √(1 + (z / zR)²) 波面の曲率半径 R(z) = z · (1 + (zR / z)²)（z = 0 では ∞） 広がり角（半角） θ = arctan(λ / (π · w₀)) z = zR で w = √2 · w₀、 R は最小値 2 · zR になる z が zR よりずっと大きいと、w(z) ≈ z · tan θ で直線的に広がる

検証値

He-Ne レーザー（波長 633 nm）でウェスト半径 0.5 mm の例を、電卓で計算した値と照合しています。あわせて、教科書にある性質（z = zR で太さ √2 倍、曲率半径の最小値 2zR）も確かめています。
