反射防止膜（単層膜）

ガラスの表面に薄い膜を1層つけると、膜の表と裏で反射した光が打ち消し合い、反射が減ります。設計波長 λ₀ で膜厚を「4分の1波長」（膜の中で λ₀/4 の厚さ）にしたときの反射率と、波長ごとの反射率を計算します。光は面に垂直に当たるとします。長さの単位は「mm」です（550 nm = 0.00055 mm）。

膜あり膜なし（基板だけ）点線：設計波長 λ₀
使っている式
境界の振幅反射率 r₀₁ = (n₀ − n₁)/(n₀ + n₁)、 r₁₂ = (n₁ − nₛ)/(n₁ + nₛ) 膜を1回通る位相 δ = 2π · n₁ · d / λ 反射率 R = (r₀₁² + r₁₂² + 2r₀₁r₁₂cos2δ) / (1 + r₀₁²r₁₂² + 2r₀₁r₁₂cos2δ) 4分の1波長膜の膜厚 d = λ₀ / (4 · n₁) このときの反射率 R = ((n₀nₛ − n₁²) / (n₀nₛ + n₁²))² 反射が 0 になる膜の屈折率 n₁ = √(n₀ · nₛ) 膜なしの反射率 R = ((n₀ − nₛ) / (n₀ + nₛ))²

検証値

教科書の単層反射防止膜の条件（n₁ = √(n₀nₛ)、d = λ₀/4n₁）と、4分の1波長膜の簡単な反射率の式で電卓計算した値と照合しています。MgF₂（フッ化マグネシウム、n = 1.38）をガラスに付けた場合の約1.26%は教科書によく出る値です。
