プリズムの最小偏角

プリズムを通った光は、入った向きから曲がって出てきます。この曲がった角度を「偏角」といいます。入射角を変えると偏角は変わり、ある入射角で一番小さくなります。これが「最小偏角」です。頂角（光が通る2つの面のなす角）と屈折率から求めます。プリズムのまわりは空気（屈折率1）とします。角度の単位は「°」です。

偏角 δ最小偏角の点点線：入力した入射角
使っている式
最小偏角 n = sin((A + δmin)/2) / sin(A/2) → δmin = 2 · arcsin(n · sin(A/2)) − A 最小偏角のときの入射角 θ₁ = (A + δmin)/2（光はプリズムの中を左右対称に進む） 任意の入射角での偏角（スネルの法則を2回使う） 入口 sin θ₁ = n · sin θ₁' 出口 θ₂' = A − θ₁'、 sin θ₂ = n · sin θ₂' 偏角 δ = θ₁ + θ₂ − A n · sin θ₂' > 1 のときは出口で全反射して、光は出てこない 頂角が小さいときの近似 δ ≈ (n − 1) · A

検証値

sin30° = 1/2、sin45° = 1/√2、sin60° = √3/2 などの公知の値と、電卓で計算した値、薄いプリズムの近似式 δ ≈ (n−1)A と照合しています。

条件期待値計算値判定
計算結果は参考値です。設計などに使う前に必ず確認してください。
