マルスの法則（偏光板を通る光の強さ）

直線偏光（振動の向きがそろった光）が偏光板を通ると、強さは角度 θ に応じて弱まります。θ は「光の偏光の向き」と「偏光板の透過軸（光を通す向き）」のなす角です。角度の単位は「°」です。強度の単位は自由で、出力も入力と同じ単位になります。

透過率 I/I₀点線：現在の角度
使っている式
マルスの法則 I = I₀ · cos²θ 透過率 I / I₀ = cos²θ θ = 0° で全部通り、θ = 90°（直交ニコル）で 0 になる 無偏光の光を1枚目に通すと、強さは I₀ / 2 になる

検証値

cos の公知の値（cos30° = √3/2、cos45° = 1/√2、cos60° = 1/2 など）から手計算した値と照合しています。
