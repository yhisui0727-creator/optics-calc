ブラッグ反射

結晶の中では、原子が並んだ面（格子面）が等しい間隔 d で重なっています。X線などの波を当てると、各面で反射した波が強め合う角度があります。これがブラッグ反射です。格子面の間隔と波長から、反射が強くなる角度 θ を求めます。θ は格子面と入射光のなす角です。長さの単位は「mm」（0.15406 nm = 0.00000015406 mm）、角度は「°」です。

1次2次3次点線：入力した λ/d
使っている式
ブラッグの条件 n · λ = 2 · d · sinθ → θ = arcsin(n · λ / (2 · d)) X線回折の測定でよく使う回折角 2θ sinθ は 1 を超えられないので、反射が起きる次数は n ≤ 2d / λ まで 角度から間隔を求める d = n · λ / (2 · sinθ)

検証値

sin30° = 1/2、sin45° = 1/√2 などの公知の値から手計算した値と照合しています。あわせて、X線回折の標準データとしてよく知られた「シリコン (111) 面を Cu Kα 線で測ると 2θ ≈ 28.44°」とも照合しています（格子定数 0.5431 nm）。
